# rsystems

Collection of opinionated, rust-based distributed systems that interop or can be used independently. Intended as a project to bridge the gap between backend and systems engineering for my own learning. This also serves as practice for implementing various distributed systems scenarios, and experimenting with advanced testing methods.

The various systems that will be implemented (not necessarily in order):
- Server
- Proxy
- Cache
- Message Queue (pub/sub)
- Worker
- Cron Jobs
- Secret Store
- Database (?)
- Object Store (?)
